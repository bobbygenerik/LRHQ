# LivingRoom HQ — Design System (MASTER)

Canonical visual source of truth for the `experimental/paint-visual-universe` rebuild.
All Compose tokens in `:core:ui` must reference this document. No rogue hex values in screens.

Generated by `/paint` from validated theses. Stack: **Android TV · Jetpack Compose · OLED**.

---

## Theses

### Visual

OLED-black cinematic living room with liquid cool-glass panels, original green brand accent,
expressive sans with strong 10-foot size contrast, airy spacing on Home/Ambient and denser
instrument spacing on Live/Apps/Command Center, soft-radiused glass surfaces elevated by
blur-illusion and cool bloom — not heavy borders or Material drop shadows.

### Interaction

Medium cinematic motion (220–400ms, ease-out / soft no-bounce spring), focus states use
cool edge-glow and slight scale (≈1.02) instead of hover, tab/rail transitions stay vertical
and restrained, Ambient enters via slow opacity/vignette fade (400ms+); **forbidden:** bounce,
elastic overshoot, neon cyberpunk flicker, warm brand accents, touch-centric ripples.

### Audience zones

| Zone | Density | Character |
|------|---------|-----------|
| Home, Ambient | Airy / lounge | Quiet chrome, hero-first, low status noise |
| Live, Apps, Command Center | Dense / instrument | More data, tighter gaps, still glass |

## Elevation / glass

No Material elevation shadows. Depth = layered translucent fill + sheen + hairline + cool focus bloom.

- Default: `GlassFill` + top sheen + `GlassStroke`
- Focus: `GlassFillFocused` + Accent stroke + optional sheen sweep (rails: sheen off)
- True `RenderEffect` blur: **not** used (Shield 60fps budget); gradients fake frost

## Motion

| Token | Value | Use |
|-------|-------|-----|
| `Fast` | 180ms | Color / stroke snaps |
| `Normal` | 280ms | Focus settle, micro UI |
| `Slow` | 400ms | Tab / zone crossfade |
| `Ambient` | 480ms | Ambient enter / vignette |
| `FocusScale` | `1.02` | Focus grow |
| `FocusSpring` | damping **NoBouncy**, stiffness Medium | Focus scale |
| `EaseOut` | `FastOutSlowIn` / cubic ease-out | Most tweens |
| `Stagger` | 40ms | Rail item enter (sparingly) |

**Forbidden:** `LowBouncy`, elastic, bounce, scale ≥ 1.04, linear UI motion (sheen sweep may stay linear).

Reduced motion: `CustomSettings.animations != "Smooth"` → snap scale to 1, skip sheen / ambient drift.

**Code:** `HqMotion` in `Motion.kt`
